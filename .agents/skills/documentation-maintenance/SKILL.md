## Rules

- Generated files are never edited by hand: change the route comments and run `docker run --rm -v "$PWD":/w -w /w node:22-alpine node api/scripts/api-docs.js`; change a Synty pack and run the build command in `build-catalog.mjs`'s header. After editing `web/public/script/functions/`, rebuild with `web/scripts/compress-functions.js`.
- A new env var goes to `compose.yaml` (or `compose.dev.yaml` if development only), `.env.example` with a comment, and the AGENTS.md list.
- A new test or tooling command goes to AGENTS.md (Frontend Standards → Lint and test) and CONTRIBUTING.md.
- Every command written in a doc runs through Docker, as AGENTS.md requires.
- JSDoc on every touched exported function, class method and route (the route's first line is `METHOD /path`); short comments only where ordering, locks, rounding or parity with the old PHP are not obvious.
- Documentation is in English; user-facing strings in pages and emails are Portuguese.

## Checks before finishing

- Grep the docs for each renamed path, command, env var, route and error code (`git grep -n '<old name>'`) and fix every stale hit.
- `docs/api/README.md` regenerated when routes changed; every path a doc names exists (`git ls-files`).
